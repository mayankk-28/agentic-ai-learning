# Agentic AI Learning

A small learning repository for understanding core agentic AI patterns.

## Notebooks

### 1) Intro to Agentic AI
- **Notebook:** `notebooks/01-intro-agentic-ai.ipynb`
- **Description:** Beginner-friendly introduction with a tiny deterministic environment and rule-based agent.
- [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mayankk-28/agentic-ai-learning/blob/main/notebooks/01-intro-agentic-ai.ipynb)

### 2) Reinforcement Learning Basics
- **Notebook:** `notebooks/02-reinforcement-learning-basics.ipynb`
- **Description:** Minimal Q-learning training loop, transition dataset sample, and training curve plot.
- [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mayankk-28/agentic-ai-learning/blob/main/notebooks/02-reinforcement-learning-basics.ipynb)

### 3) Multi-step Agent Pipeline
